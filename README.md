# K-API HUB 🇰🇷

> 한국의 모든 공개 API를 한곳에 모은 개발자 허브

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/bubilife1202/k-api-hub)

## 📌 소개

K-API HUB는 한국의 공공데이터, 빅테크 API, 그리고 유용한 개발자 도구들을 한곳에 모아 검색하고 사용할 수 있는 웹 서비스입니다.

### 주요 기능

- 🔍 **스마트 검색**: Fuse.js 기반의 퍼지 검색으로 빠르게 원하는 API 찾기
- 📁 **카테고리 필터**: 금융, 교통, 지도, 생활, AI, 공공데이터 등으로 분류
- ⭐ **즐겨찾기**: 자주 사용하는 API를 로컬에 저장
- 💻 **코드 생성기**: cURL, JavaScript, Python 예제 코드 자동 생성
- 📱 **반응형 디자인**: 모바일부터 데스크톱까지 최적화된 UI
- 🎯 **SEO 최적화**: 검색 엔진에 최적화된 구조

## 🚀 기술 스택

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/UI (Radix UI)
- **Icons**: Lucide React
- **Search**: Fuse.js
- **Deployment**: Vercel

## 📦 포함된 API (58개+)

### 지도 & 위치
- Kakao 지도, Naver 지도, T맵, VWorld

### 금융
- Toss Payments, PortOne, Kakao Pay, Naver Pay

### 교통
- 서울시 버스, 지하철, KTX, 따릉이

### 공공데이터
- 아파트 실거래가, 미세먼지, 날씨, 약국/병원 정보

### 인공지능
- Clova OCR, Papago, Kakao Vision, Clova Speech

### 생활
- Kakao/Naver Login, 우편번호 검색, 검색 API

## 🛠️ 로컬 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm start
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어보세요.
